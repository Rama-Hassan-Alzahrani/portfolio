CloudVista: Cloud Cost Insight Tool for Infrastructure-as-Code

Graduation Project In Progress

CloudVista helps development and DevOps teams that manage their cloud setup with Terraform see what each code change will cost before it is deployed. It then compares that estimate with the real AWS and Azure bill, explains which change caused a cost increase, and warns the team before they go over budget.

FitTrack: Gym Membership & Health Tracking System

Group Project In Progress

An Oracle database for a gym that manages members, trainers, membership plans, subscriptions and payments, gym check-ins, and members' health and workout records. It blocks entry when a subscription has expired and produces reports such as monthly income, expiring subscriptions, and each member's progress.
